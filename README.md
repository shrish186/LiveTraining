# Live Training Intelligence

Live training calls for athletes in any sport, from a body-worn motion sensor plus WHOOP heart
rate and recovery. v1 is the data pipeline: record, upload, analyse.

- `backend/`: FastAPI server (WHOOP OAuth, recovery and sleep, session storage)
- `analysis/`: offline analysis and synthetic data
- `mobile/`: Flutter app
- `profiles/`: sport profiles
- `docs/`: session format spec

Setup steps for each part will be added as each part is built.
